What was measured

Two-stage baseline; single-stage sweeps

Geography uses two dependent calls with approximately 1,500 input tokens and 100 output tokens per call. Context, output, concurrency and cache sweeps use one model call per workflow. All timing is measured at the client.

Exact validation, before latency inclusion

Structured output must match the expected schema and field values. Completion and token usage must be present. HTTP 200 alone is insufficient. A failed first call prevents the dependent second call.

Synthetic structured-output workload

GPT-5.4 (2026-03-05) and GPT-5.4 Mini (2026-03-17), reasoning effort none, Managed Identity, 100,000 TPM per deployment, and no automatic SDK retries. Output length is controlled through a schema-constrained audit note. This does not represent unconstrained prose or a production application.

Routing and timing boundaries

Resource region does not identify the model's processing location. Global Standard can route globally; EU Data Zone is constrained to its data zone. First visible content is a client event, not the service's TTFT metric. SSE events are not individual tokens.

Snapshot and temporal limits

Comparisons are exploratory

Case-matched comparisons include only pairs where both workflows were correct. Conditions were not necessarily measured simultaneously. Bootstrap intervals do not correct for temporal dependence or multiple comparisons. Concurrency tests use synchronized, quota-paced bursts, not unlimited offered load.

Evidence scope and reproducibility

    Underlying observations and runtime configuration are not embedded. This file contains aggregate test results only. Method and analysis code accompany the benchmark; archive hashes identify the verified inputs but do not make those inputs independently inspectable.
